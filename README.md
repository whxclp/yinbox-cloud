# 音盒 · 云端版（GitHub Pages）

你的私人云端音乐播放器：歌曲文件放在网上，手机、电脑、任何设备打开网页就能听。
免注册、无广告、完全免费。

## 文件说明

| 文件/文件夹 | 作用 |
|---|---|
| `index.html` | 播放器页面（核心，不要改名） |
| `songs.json` | 歌单登记表（每首歌一行） |
| `songs/` | 歌曲文件都放这个文件夹（mp3 等） |
| `README.md` | 本说明 |

## 一、部署（只需做一次，约 10 分钟）

> **当前状态**：`songs.json` 已登记好 33 首歌，`songs/` 文件夹里已放好对应歌曲文件。你只需要把**整个文件夹**上传即可，不用自己整理。

1. 打开 https://github.com 登录你的账号
2. 点右上角 **+ → New repository**，名字随便起（如 `yinbox-cloud`），选 **Public**，点 **Create repository**
3. 在仓库页面点 **uploading an existing file**（上传现有文件）
4. 把 **D:\yinbox\cloud 文件夹里的 `index.html`、`songs.json`、`songs` 文件夹**一起拖进去上传（点 Commit changes）
5. 点仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 **main** 和 **/(root)**，点 **Save**
6. 等 1~2 分钟，页面顶部会出现你的网址：`https://你的用户名.github.io/仓库名/`
   （仓库名大写会变成小写；网址打不开就多等一会或刷新）

以后手机/电脑浏览器打开这个网址，就是你的音乐播放器。

> 有 3 首超大合集（100首白兰的2026热门雷鬼版歌曲合集 186MB、6小时精选DJ串烧 162MB、韩宝仪珍藏金曲 180MB）超过 GitHub 单文件 100MB 限制，**未包含在云端**，继续用家里电脑版听即可。

## 二、添加歌曲（以后每次加歌都这样）

1. 电脑上把歌文件（如 `我的歌.mp3`）**重命名成没有中文和空格**的名字更稳，如 `my_song.mp3`
2. 打开 GitHub 仓库，进 `songs` 文件夹 → **Add file → Upload files** → 拖入歌文件 → **Commit changes**
3. 再打开 `songs.json` → 点铅笔（编辑）→ 按下面的格式加一行（注意逗号和引号）→ **Commit changes**

```json
{
  "songs": [
    { "title": "歌名", "artist": "歌手", "file": "songs/my_song.mp3", "lrc": "" }
  ]
}
```

- `title`：显示的歌名（不填会显示文件名）
- `artist`：歌手（可留空）
- `file`：**必须**，文件路径，和 `songs/` 里一致
- `lrc`：歌词，可留空；有时间轴歌词（LRC 格式）贴进来可逐句显示

想批量加歌：也可以把全部歌上传后，一次性把 `songs.json` 编辑好（每首歌一行）。

## 三、使用

- 打开网址 → 看到歌单 → 点歌播放
- 顶部可筛选歌名/歌手；「只看收藏」按钮
- 每首歌右侧 ♡ 点一下变 ♥ 收藏（收藏存在**当前设备**的浏览器里，换设备不通用，这是纯静态网页的限制）
- 播放器：上一首/播放/下一首、进度条点击跳转、顺序/循环/单曲/随机模式、音量开关
- 歌曲按「歌曲 / 器乐曲」自动分组（歌名含乐器名如二胡、钢琴会归到器乐曲）

## 注意事项

- 纯静态网页**没有在线搜索功能**（搜新歌请用家里电脑上的完整版音盒）
- GitHub 国内访问偶尔慢或打不开，属免费方案的常态
- 单首歌文件不要超过 100MB（GitHub 限制）
